# Profile assets

The logo was redrawn as vector paths from the image supplied by the profile owner. It contains no embedded bitmap. White, blue, dark and square versions are included.

The hero uses Sora lettering converted to paths so it renders without a font server. Sora is by the Sora Project Authors: https://github.com/sora-xor/sora-font. Font license: SORA-OFL.txt. Outlined lettering remains scalable; editable text is in the build source.

hero.svg is the desktop composition; hero-mobile.svg is selected below 600px. Both include a slow orbit animation with a prefers-reduced-motion fallback. Native README text remains selectable and readable independently of images. All visual assets are stored in the repository, with no external badge or stats services.

The PNG files under previews are local renders of the original SVG/README assets for review, not raster source assets.
